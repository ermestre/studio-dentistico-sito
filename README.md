# International Dental Clinic - sito

Pagina pubblica della clinica: servizi, video (link alle pagine Facebook), dove siamo, QR code e pulsante WhatsApp. Italiano e albanese.

- Nessun dato di pazienti in questo repository.
- Per cambiare video: modifica l'array `VIDEOS` in `public/index.html`.
- Per cambiare testi o numeri: modifica l'oggetto `T` nello stesso file.

Pubblicazione: Cloudflare Workers con assets statici dalla cartella `public/`.
